# Trabajo Practico Integrador

Trabajo Práctico Integrador de Programación Web 1.
Integrantes: Badiali Florencia y Fernandez Ana Laura.

Desarollo de un sitio web responsive de 3 páginas (principal, artículo y contacto) desarrollado con HTML, CSS y JavaScript puro. Incluye navegación con Flexbox, formulario con validaciones en JS, carrusel de imágenes personalizado y despliegue en GitHub Pages.
